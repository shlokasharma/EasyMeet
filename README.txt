EasyMeet

1) Overview

EasyMeet is a responsive appointment booking web application that enables users to schedule, manage, and track appointments through an intuitive web interface. The application includes user authentication, appointment history, search functionality, and an administrative dashboard.

2) Features

-> User authentication
->Appointment booking
-> Appointment history
->Search functionality
-> Admin dashboard
-> Responsive user interface
-> Dark mode support


3) Tech Stack

-> HTML5
-> CSS3
->JavaScript


4) Project Structure

EasyMeet/

│── login.html
│── booking.html
│── history.html
│── admin.html
│── confirmation.html
│── css/
│── js/
│── images/



5) How to Run

Clone the repository

```bash
git clone https://github.com/shlokasharma/EasyMeet.git
```

Open `index.html` in your browser.
